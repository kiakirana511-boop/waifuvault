# WaifuVault V9.4 Real Voice Player

V9.4 mempertahankan UI cosmic/Hoshino dari V9.3, tapi tab Voice sekarang jadi audio player lokal.

Fitur baru:
- Scan audio dari folder internal: `/storage/emulated/0/DCM Waifu/Voice/`
- Scan audio dari folder SD card: `/storage/4394-15F8/DCM Waifu/Voice/`
- Support file: mp3, wav, m4a, aac, ogg
- Play / pause / next / previous
- Progress durasi audio
- Spectrum visualizer ringan yang bergerak saat audio diputar
- UI Home/Gallery/Profile tetap aman dari V9.3

Catatan: visualizer V9.4 adalah frequency-style ringan dulu, bukan FFT native real-time berat. Kalau kurang puas, V9.5 bisa dicoba true real-time visualizer.
